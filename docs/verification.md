## October 26 durable admission

Implemented a persisted database-wide retained-URL cap, default 1,000, shared by seeds and discovery. PostgreSQL jobs are the usage ledger. Existing normalized URLs keep their IDs at exhaustion; new seeds receive 409. Already admitted pages finish indexing with a count of distinct discovered URLs rejected by capacity. This is a URL count policy rather than a disk quota, per-user rate limit or public-web permission.

## October 26 robots policy

Added an explicit CrawlIndex product token/header, pinned Google-port matcher, bounded per-origin robots fetches and persisted shared positive/error cache. Denials become terminal failed jobs without fetching/indexing the page. Unreachable/invalid policy defers page access through the existing durable retry/attempt mechanism; ordinary 4xx is cached as unavailable/allow. Exact operational choices and conservative deviations are in [architecture](architecture.md#robots-decisions).

Local PostgreSQL/static/race checks passed (command package 1.023s, crawler package 13.730s) with case/merged-group, precedence, wildcard/end-anchor, Unicode/percent-encoding vectors; twenty concurrent cache decisions made one policy request; new connections reused cache, and expiry caused a refetch. A denied job made zero protected-page requests, produced no document and no Secretword search result. A cached 503 set durable future availability; the terminal attempt boundary was separately checked with controlled database attempt/availability values, not represented as three elapsed network retries. ## Connection-time DNS/IP egress

The next implementation adds a shared page/robots dial boundary, with numeric dialing after one checked resolution. [Exact semantics and limits](egress.md) include conservative static ranges, mixed-answer rejection, IPv4 mapping, pooled connections and a narrowly configured local-fixture exception. Default local/metadata destinations are denied even when their origin was admitted. Denial uses the existing durable retry/terminal behavior rather than creating another queue or overriding admission.

Local `go vet ./...` and the complete real-PostgreSQL `go test -race -count=1 ./...` passed (command package 1.036s; crawler package 14.488s). Deterministic tests cover IPv4/IPv6 private/link-local/special classes, mapped and scoped literals, mixed public/private answers, new-connection rebinding, numeric fallback, resolver/dial deadlines, partial/empty/excessive DNS results and the exact fixture host/port/scheme restriction. A local TLS server verifies the original Host/server name and valid trust path, rejects an untrusted certificate, then receives zero page/robots dials after the injected DNS answer changes to loopback. Resolver/dial injection maps synthetic public answers only to controlled local servers; these are not tests against public endpoints. Existing redirect/body/robots/admission/search, lease/process recovery and shutdown cases passed.
